Telegram Accounts API

Buy Telegram account numbers and fetch their login codes from your own server. Every call is a GET request that returns JSON. Prices and balance are in INR.

This API is for the Telegram service only.Other services in the Prime Store bot are not available through it. You can still use them in the bot as usual.
Base URLhttp://145.239.65.118:20060

Get started

Your apiKey and YourID are in the bot under Menu → API. Send both with every request. The flow for one account is:

  • Call getNumber to buy a number.
  • Log in to Telegram with that number.
  • Call getCode until the code arrives.

Security

Call the API from your own server only.Your key is part of every request, so anything running on the user’s side, such as a browser or a mobile app, can reveal it.
  • Open Menu → API → IP whitelist and add your server’s IP address. The key then works only from that address, even if it leaks.
  • If you think the key was exposed, tap Regenerate API key on the same screen.
  • Keep the key in an environment variable, and do not print full request URLs in your logs.
  • This API currently runs over plain HTTP, so the whitelist matters. Use it.

Get country information

GETaction=country_info

Returns stock and price for one country. Without country_code you get every country.

ParameterTypeRequired
apiKeyStringYes
YourIDStringYes
country_codeStringNo
All countries
?action=country_info&apiKey=YOUR_API_KEY&YourID=Your_ID
One country
?action=country_info&apiKey=YOUR_API_KEY&YourID=Your_ID&country_code=uz
Response
{
  "status": "ok",
  "name": "Uzbekistan 🇺🇿",
  "code_Num": "40",
  "code": "UZ",
  "qty": 6450,
  "price": "75"
}

Buy number

GETaction=getNumber

Buys a phone number from one country. The price is taken from your balance. If no number could be bought, you are not charged.

ParameterTypeRequired
apiKeyStringYes
YourIDStringYes
country_codeStringYes
maxPriceStringNo

maxPrice is in INR. If the price is higher, nothing is bought.

?action=getNumber&apiKey=YOUR_API_KEY&YourID=Your_ID&country_code=uz
Response
{
  "status": "ok",
  "name": "Uzbekistan 🇺🇿",
  "Number": "+99800000000",
  "price": "75",
  "new_balance": 140.5
}

Get code

GETaction=getCode

Returns the login code for a number. Log in with the number in Telegram first, then call this. If the code has not arrived yet you get code_not_received: wait a few seconds and call again. A received code stays available for 30 minutes.

ParameterTypeRequired
apiKeyStringYes
YourIDStringYes
numberStringYes
?action=getCode&number=+99800000000&apiKey=YOUR_API_KEY&YourID=Your_ID
Response
{
  "status": "ok",
  "Number": "+99800000000",
  "code": "47607",
  "pass": "2345GD8R"
}

pass is the account’s two-step password. It is empty when the account has none.

Errors

When something goes wrong the answer has "status": "error", a short code and a readable message. The HTTP status matches.

{
  "status": "error",
  "code": "insufficient_balance",
  "message": "Not enough balance. Add funds in the bot first."
}
HTTPcodeMeaning
400missing_parameter invalid_parameter invalid_actionA parameter is missing or wrong
401invalid_credentialsapiKey or YourID is wrong
402insufficient_balanceYour balance is too low
403ip_not_allowedThe key is right, but your server’s IP is not on its whitelist
404country_not_found number_not_found code_not_receivedNothing found, or the code has not arrived yet
409out_of_stock price_too_high no_number order_not_activeThe request can’t be done right now. You are not charged
410code_expiredThe code is no longer available
429too_many_requests busyToo many requests: wait a little
503service_unavailable order_checkingService is busy. order_checking means the order is being checked: do not retry, contact support

Examples

curl
curl "http://145.239.65.118:20060?action=getNumber&apiKey=YOUR_API_KEY&YourID=Your_ID&country_code=uz"
Python
import requests, time

BASE = "http://145.239.65.118:20060"
AUTH = {"apiKey": "YOUR_API_KEY", "YourID": "Your_ID"}

r = requests.get(BASE, params={"action": "getNumber", "country_code": "uz", **AUTH}).json()
if r["status"] == "ok":
    number = r["Number"]
    for _ in range(30):                      # wait for the code
        c = requests.get(BASE, params={"action": "getCode", "number": number, **AUTH}).json()
        if c["status"] == "ok":
            print(c["code"], c["pass"])
            break
        time.sleep(5)
else:
    print(r["code"], r["message"])
